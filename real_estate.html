Real Estate Price Forecasting

Project Overview

This project focuses on forecasting real estate prices in Connecticut using historical property sales data. With over 1.2 million records from 2001 to 2024, we applied time-series modeling to predict pricing trends.

Problem Statement

Real estate markets are influenced by complex temporal patterns. The goal was to uncover seasonal and macro trends and generate accurate forecasts that support both investment and policy decisions.

Dataset & Sources

  • Source: Connecticut Open Data (Real Estate Transactions)
  • Records: 1.2M+ property transactions
  • Features: Sale Date, Sale Amount, Property Location, Year Built, Property Type

Methodology

  • Used PySpark to preprocess and clean large-scale transaction data
  • Applied Facebook Prophet for time-series modeling and forecast generation
  • Resampled monthly sales and removed outliers to improve trend visibility
  • Evaluated model using R² and RMSE (R² = 0.92)

Model Prediction & Evaluation

The model captured strong seasonal patterns in Connecticut's housing market. Monthly forecasted values closely matched actual sales trends. The interactive dashboard offers filtering by county and year range.

Real-World Impact

The forecasting system helps local agencies, buyers, and investors anticipate future pricing. By understanding regional price behavior, stakeholders can make more informed real estate decisions.
