AI-Powered News Research Tool

Project Overview

This project aims to simplify news consumption by allowing users to input multiple article URLs and ask questions in plain English. The tool returns concise, AI-generated answers with relevant source links.

Problem Statement

In a world overwhelmed with news, it's hard to quickly understand and verify key insights across multiple sources. This tool helps users:

  • Summarize complex articles efficiently
  • Extract insights in real time
  • Ask natural-language questions about news
  • Get source-backed answers for transparency

Tech Stack

  • Backend: Python, LangChain, OpenAI API, FAISS, python-dotenv
  • Frontend: Streamlit
  • Features: News URL input, semantic search, chunked text analysis, citation-enabled answers

🎬 Live Demo

This demo shows how the tool extracts news insights, answers questions using LLMs, and provides credible sources — all in real-time.

System Architecture

The system uses recursive chunking to preserve context from article text. FAISS indexes the chunks for fast similarity search. LangChain connects OpenAI's LLM to the FAISS index and Streamlit serves as the interactive user interface.

Functionality Highlights

  • Input multiple news URLs
  • Ask natural language questions
  • Receive summarized responses with citations
  • Toggle between articles or download extracted content

Real-World Impact

This tool enables faster, more transparent news consumption. Journalists, researchers, and everyday users can quickly verify, compare, and understand large volumes of news with AI-assisted summaries and traceable references.
