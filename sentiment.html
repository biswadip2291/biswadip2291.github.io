Sentiment Classification of Movie Reviews

Project Overview

Engineered a sentiment analysis pipeline for over 50K movie reviews. Integrated traditional NLP techniques such as Bag of Words, Bigrams, POS tagging, and LIWC feature extraction. Models were evaluated with Random Forest and SVM, with accuracy optimized via hyperparameter tuning.

Problem Statement

Identifying nuanced sentiment in movie reviews poses challenges due to varied language use. Our aim was to develop a robust model using a diverse set of features to accurately classify sentiments on a multi-class scale.

Dataset and Sources

  • Source: Movie review dataset shared in NLP coursework (2024)
  • Total Records: ~50,000+ labeled reviews with ratings (0–4 scale)
  • Features: Tokens, POS, sentiment lexicons (SL), LIWC-based categories

Methodology

  • Performed preprocessing: lowercasing, punctuation removal, stopwords filtering
  • Extracted unigram, bigram, POS, SL, LIWC, and Combined SL-LIWC features
  • Trained Random Forest and SVM models on both filtered and unfiltered datasets
  • Evaluated accuracy using 5-fold cross-validation

Model Prediction & Evaluation

Across classifiers, the Combined SL-LIWC feature consistently delivered strong results, indicating its value in capturing both linguistic and psychological cues. Random Forest outperformed SVM, especially on filtered data. Unigram (0.56) and LIWC (0.54) features also performed well. The Combined SL-LIWC set remained stable across both filtered and unfiltered contexts.

Feature Set Unigram Bigram POS SL LIWC Combined SL-LIWC

Unfiltered 0.52 0.44 0.48 0.44 0.52 0.48

Conclusion

The use of linguistically rich and psychologically grounded features improved sentiment classification performance. Filtering had mixed effects depending on the model and feature type. Overall, ensemble models like Random Forest combined with LIWC and SL-based features offered the most robust results.

Real-World Impact

This sentiment classification framework can support content moderation, brand monitoring, and customer experience analysis. Its high performance using interpretable features like LIWC and sentiment lexicons makes it ideal for use in product reviews, movie feedback, and social media analytics.
