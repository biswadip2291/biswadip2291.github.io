Video Games Sales Analysis

Project Overview

This project combines data from Steam and VGChartz to visualize game trends, player behavior, and global console sales. Using Tableau dashboards, we explored pricing strategies, engagement, regional preferences, and genre transitions.

Problem Statement

Game developers and marketers need actionable insights into what makes games popular, how pricing affects sales, and how users interact across genres and platforms. Our goal was to visualize those patterns using clean, interpretable dashboards.

Data Sources

  • Steam data (via SteamSpy) – real-time PC game metrics
  • VGChartz data – console sales from 2000 to 2023 (vgchartz.com)

Interactive Dashboards

Explore five Tableau dashboards that highlight key insights across genre value, player behavior, pricing models, and console sales — beginning with a global snapshot.

Opening Dashboard

81% of Steam reviews were positive, with an average playtime of 78 hours. Action games lead in engagement.

Dashboard 1: Genre Value Analysis

Compare genres by pricing, playtime, and review scores to evaluate market value.

Dashboard 2: Genre Popularity & Player Behavior

Visualizes how players interact across popular genres like Action, RPG, and Strategy.

Dashboard 3: Free vs Paid Games

Analyze how pricing correlates with user ratings and review volume.

Dashboard 4: Console Sales Trends

PlayStation dominates global sales. GTA V leads across all platforms.

Additional Insights

  • Added filters for genre, platform, region, and price for dashboard interactivity.
  • Used chord diagrams to visualize genre-switching behavior.
  • Calculated positive review ratios to discover patterns not visible in raw data.

Conclusion

Action and RPG dominate playtime. Indie and Puzzle games are highly rated despite lower cost. PlayStation rules in console sales. These dashboards offer developers valuable insights into pricing, platform popularity, and player behavior across game types.
